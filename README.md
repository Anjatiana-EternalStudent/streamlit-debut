# streamlit-debut

This is my first project using **Streamlit**. I built a Body Mass Index (BMI) calculator to get hands-on experience with the framework.

## Features
* Live BMI calculation based on user height and weight inputs.
* Dynamic classification and color-coded status using Python's `next()` and `zip()` loops for optimal performance.

## How to run it
You can run this project globally or via a virtual environment.

### Option A: Using Pipenv (Recommended)
This project includes a `Pipfile` for an isolated environment:
1. Install dependencies: `pipenv install`
2. Run the app: `pipenv run streamlit run app.py`

### Option B: Using standard Pip
If you prefer not to use the Pipfile, you can install Streamlit globally or in your own virtual environment:
1. Install Streamlit: `pip install streamlit`
2. Run the app: `streamlit run app.py`
